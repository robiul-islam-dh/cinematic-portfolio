# Monika Hossain — Cinematic Portfolio (No Install Required)

This is the easiest version to run and deploy. It uses plain HTML, CSS and JavaScript, so **Node.js and npm are not required**.

## Run locally

Double-click `index.html`, or serve the folder with any simple static web server.

## Deploy free on GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save. GitHub will publish the portfolio for free.
